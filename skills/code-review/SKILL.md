# 代码走查清单

按以下四组逐项检查，输出「通过/问题列表（含位置与建议）」：

1. **安全性**：输入未校验、注入、越权、密钥硬编码
2. **边界**：空值/空数组/超长输入、除零、循环终止条件
3. **可读性**：命名表意、函数单一职责、无用代码
4. **测试**：改动点是否有测试覆盖、是否破坏既有断言

结论格式：`[CR] 通过` 或 `[CR] N 个问题：file:line 描述`。
